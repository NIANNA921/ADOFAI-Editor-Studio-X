# ADOFAI Editor Studio X

《冰与火之舞》的谱面编辑器工作台。叠在游戏原生编辑器之上，提供**不进游玩状态**的实时预览、时间轴浏览和事件参数编辑。

> **最新版本：0.95.0** · 基线 AES 0.40.0 · 默认主题 NEXT
>
> 纸白淡紫浅色主题、时间轴波形、自动同步联机、自动补丁程序均已更新。

当前版本 **0.95.0**，基于 AES 0.40.0，默认使用 **NEXT** 深色主题；设置里可切到 **纸白淡紫** 浅色或 **原生**。界面优先使用 **Microsoft YaHei UI Light**，并统一加大字号与圆角。

## 0.95.0 更新摘要

- **纸白淡紫主题**：白色面板 + 淡紫强调；纸白使用 Microsoft YaHei Light，关闭合成粗体；设置里可切回 NEXT / 原生。
- **时间轴波形**：从谱面目录读取 `.ogg`，绘制连续包络；支持波形峰值吸附和 BPM 节拍网格。
- **浅色 UI 收尾**：顶栏模式改成圆角按钮（NEXT 同步，原生不动）；版本页按主题切换 logo；帮助页加群提示移到底部；设置开关滑块独立着色。
- **联机**：自动同步开关 + 分钟输入；加入失败会明确提示，不再卡在下载媒体。
- **自动补丁**：配套 `AESX-Patcher-0.95.0`，生成前先输入版本号，自动补 UnityWebRequest 引用。

## 它解决什么问题

原版编辑器里想看一段效果，只能按播放、看完、再退回来改。工作台把这层拆开：

- **拖时间轴就出画面** —— 不调原版的 `Play()`，不触发读秒、判定和游戏状态变化
- **一屏看全所有事件** —— 几百上千个事件块按时间装箱，纵向高度只等于「同时重叠的事件数」
- **改参数不用翻原生面板** —— 右侧参数栏由游戏自身的属性元数据生成

## 安装

把压缩包里的 `ADOFAIEditorStudioX` 文件夹整个放进游戏的 `Mods` 目录：

```
<游戏目录>/Mods/ADOFAIEditorStudioX/
├── Info.json
├── ADOFAIEditorStudio.dll     ← mod 本体（程序集名保持兼容）
├── AesIcon.rgba               ← 左下角入口按钮图标
├── AesxLogo.png               ← NEXT / 原生的版本页 logo
├── AesxLogoLight.png          ← 纸白淡紫的版本页 logo
├── AesxFont.ttf               ← 纸白主题字体
└── LICENSE
```

启动游戏，在 Unity Mod Manager 里确认 mod 已加载（显示「ADOFAI Editor Studio X」）。

## 怎么打开

1. 进游戏的关卡编辑器，打开一张谱面
2. 点编辑器**左下角的圆形按钮**（贴在播放键右边）
3. 按 **Esc** 关闭

> 这个按钮是唯一入口，**没有键盘快捷键**。F8 试过，实测有用户的 F8 根本进不了 Unity（笔记本 F 键默认走媒体键，或被录屏 / 输入法 / 显卡 overlay 抢了全局热键）。

打开后默认是**只读**，要改东西先切到编辑模式。

## 界面主题

设置 → 常规设置 → 界面主题现在有三套：

- **纸白淡紫**：白色面板 + 淡紫强调，浅色 UI；使用 Microsoft YaHei Light，关闭合成粗体。
- **NEXT**：AESX 原本的分层深灰 + 蓝色强调；
- **原生**：AES 0.40.0 原本的纯灰阶。

切换主题会重建整个工作台，选中、滚动位置等瞬时状态会重置。

纸白主题的版本页使用黑白 `AesxLogoLight.png`；NEXT / 原生继续使用紫色 `AesxLogo.png`。顶栏模式按钮在纸白 / NEXT 下是圆角按钮，原生保持原来的倒梯形。

## 自动补丁

配套的 `AESX-Patcher-0.95.0-补丁包.zip` 用于把 AESX 的改动打到新版 AES 源码上：

- payload 共 28 个文件；
- 包含 0.95.0 的 UI、波形、联机、主题、字体与 logo；
- 自动给新版 AES 的 csproj 补 `UnityWebRequestModule` / `UnityWebRequestAudioModule`；
- 打包时把 `AesxFont.png` 还原成 `AesxFont.ttf`。

把新版 AES 源码文件夹或 zip 拖到 `run-patcher.bat` 上即可。

## 联机做谱（局域网 / 内网穿透）

联机是**主机直连**，不连服务器、不需要账号。

### 同一个局域网

1. 主机进入关卡编辑器，打开要做的谱面；
2. 点顶栏「联机」→ 填名字和端口（默认 **21587**）→「开房」；
3. 第一次开房时 Windows 防火墙会弹窗，选**允许访问**（至少允许专用网络）；
4. 加入方点「联机」；面板会自动发现房间并填好地址，直接点「加入」；
   也可以手填 `192.168.x.x:21587`。

### 异地 / 公网（自己配内网穿透）

- 只需要把 **TCP 21587** 映射到主机的局域网 IP；
- UDP **21588** 只用于局域网房间发现，远程联机不需要；
- 加入方填 `公网IP:21587` 或 `域名:端口`；
- 双方必须是**同一版本的 AESX**，协议号对不上会被拒绝；
- 联机**没有密码**，能连到端口的人就能改谱，建议只在可信网络使用。
- **远程内网穿透已实测通过**：TCP 21587 端口映射后可以正常加入、同步、编辑。

### 自动同步

- 联机面板里有「自动同步」开关，打开后旁边的分钟输入框只接受数字（1～1440）；
- 成员会按这个间隔自动向主机请求最新谱面，效果和手动点「重新同步」一样；
- 关闭开关就恢复原来的手动同步。

### 加入失败

- 连接超时、端口不是 AES 主机、握手无响应、协议不一致时，不会再卡在「下载媒体中」；
- 会退出加载，并在联机面板显示「无法加入：房间不存在或主机没有响应」等原因。

### 说明

- 主机必须先打开一张谱面才能开房；加入方拿到的是会话副本，不会覆盖主机原文件。
- 端口被占用时主机会自动尝试 +1～+5，面板会显示实际端口。
- 媒体由主机中转；成员本地新增的媒体不会自动传给其他人。
- 掉线只提示，不踢人；结构改动自动整份重推，两个人同时改同一个键时后到的覆盖先到的。

## 波形 / 重音吸附 / 节拍网格

时间轴顶部的标尺条会绘制当前歌曲的波形。拖动事件块或拖左右边缘时，波形峰值会参与吸附；按住 Alt 可临时关闭吸附。时间轴还会按谱面 BPM 画节拍线，每四拍加粗。

波形直接从谱面目录的 `songFilename`（.ogg）用 UnityWebRequest 完整解码成可读 PCM，不依赖游戏里的 Streaming 片段；文件不存在或解码失败时才隐藏，日志里会有一条 `[Waveform]` 警告。

## 自动更新

**AESX 是独立分支，已关闭上游 AES 的自动更新。**

上游清单指向官方包，继续启用会在某次清单抬高 `min` 时把本分支覆盖成官方版，Studio 主题和 X 品牌都会丢。后续如果给 AESX 建了自己的 `version.json` 清单，再在 `Main.Load` 里重新启用 `VersionGate.Check` 即可。

当前版本仍然可以在顶栏点版本号查看更新说明；联网失败不会影响使用。

## 功能一览

| 模块 | 内容 |
|---|---|
| **预览** | 21 个求值域，覆盖轨道 / 镜头 / 装饰物 / 滤镜 / 粒子 / 行星 / 音效，数学对齐游戏本体 |
| **时间轴** | 按时间装箱、拖块改时间与时长、多选批量拖、复制剪切粘贴、格号跳转、**模块分组**（画圈成组、折叠、合并） |
| **参数栏** | 由游戏属性元数据生成，支持 12 类控件，多选批量改值 |
| **左栏** | 装饰物列表（可搜索 / 隐藏 / 锁定 / 删除）+ 媒体库（拖图即建装饰物）+ 六个谱面设置页 |
| **撤销** | 工作台自己的撤销栈，与 PACL2 共存 |
| **视图锁** | 一键锁定镜头位置与缩放 |

详细的逐项说明、快捷键全表、已知问题、尚未完成的部分，见 **[功能详解.md](功能详解.md)**。
